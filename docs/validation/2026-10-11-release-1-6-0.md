# Release 1.6.0 candidate validation, 2026-10-11

Baseline: main `6c5f1ae557e8d9d3b4deea7b955f1b2bf53f1143`. This release changes package metadata and presentation, not the default tool registry or installed command surface.

## Package contract

- Version: `gsc-mcp-tools==1.6.0`, Python 3.11 or later.
- Default catalogue: 96 tools; installed commands: `gsc-cli`, `gsc-mcp`, `gsc-mcp-tools`.
- The wheel packages experimental `audit_runtime`, `native_audit`, `native_roles`, `native_process` and `query_rules` modules, including nine explicit source-review profiles.
- Audit runners, offline evaluators and the 15 shared workspace skills require a repository checkout. The source archive includes these resources; the wheel does not install them as console commands.
- The optional native launcher supports Linux/macOS. Attempt ceilings are not token or monetary budgets. No new provider acquisition or native model run is performed for this release.
