# A per-URL indexing observation matrix

`indexing_evidence_matrix` reconciles an explicit sample with supplied observations. It makes no provider request and does not crawl, render, upload or write. The result has separate inspection, HTML, search, sitemap/business inventory, imported crawl and log cells. Current indexing stays `unknown`; rendering stays unavailable. A supplied inspection verdict remains a dated reported provider observation, with unverified caller origin.

Inputs: exact `site`, 1 to 50 distinct in-scope raw `urls`, `reports_json='[]'`, optional existing `snapshot_id` and `max_reports=20` (ceiling 50). Reports have a 2 MiB total input cap, nesting/string limits, and at most 20 retained cells per URL with explicit omission counts. Raw URL identity is retained. No whole-property counts are extrapolated.

Each supplied JSON list entry is `{"report": <MCP response>, "collected_at": <optional aware ISO timestamp>}`. Accepted responses: `inspect_url`, `batch_url_inspection`, `page_technical_audit`, page-only `get_search_analytics` / `get_advanced_search_analytics`, and `crawl_log_audit`. Metadata is checked against the exact source site and selected URLs. Foreign sites, unsupported contracts, malformed fields and naive/future supplied times are rejected. Report collection times are caller-declared; absent collection times remain null. Inspection `last_crawl` is not the inspection retrieval time.

For an authorized raw sitemap/business list, a caller inventory response has `site`, `kind` (`sitemap` or `business`), `urls`, and `_meta` with `tool="caller_inventory"`, `params.site=<exact site>`. Membership is explicitly caller-declared. Do not present a normalized or truncated `sitemap_audit` visibility sample as the entire raw XML inventory. That tool's absence-of-search rows are not an indexing verdict.

An existing local SiteOne snapshot retains its declared source time, unknown selection/timezone, rejected rows and coverage. HTTP status does not establish indexation. Logs with readable paths can create path-candidate associations, explicitly query-stripped and tied to the caller-declared site; no per-path authenticated bot identity is inferred. Hidden paths produce no URL association. A request establishes neither rendering nor a citation.

The matrix retains all available contradictory observations. Reported inspection `PASS` versus HTML `noindex`, Google canonical versus HTML declaration, and caller sitemap membership versus a different declared canonical are review candidates with both source IDs. Their collection order/origin are not authenticated, so no source silently overwrites another. Supplied literal canonical chains follow at most five declared hops within the selected observations, retaining ambiguity/cycles/missing observations; no target is fetched and no Google selection is inferred. Relative declarations are not silently resolved into equivalence.

The tool ignores the legacy inspection `category` fallback when deciding observation availability. UNKNOWN/UNSPECIFIED raw states remain unavailable. Zero or absent GSC rows cannot produce `indexed=false`. Soft-404, redirects, HTTP errors and unknown robots state remain separate cells. HTML-only input cannot establish what JavaScript renders.

Start with a small sample. Acquire authorized observations separately through existing tools, keep their collection times and provider windows, and then pass those responses to this read-only matrix. The matrix records zero provider calls of its own; it does not budget or authenticate earlier calls. Before any deletion/noindex/consolidation recommendation, obtain the repository's 90-day traffic/inspection preflight and human review of purpose/intent. Contradictions alone do not authorize a write.
