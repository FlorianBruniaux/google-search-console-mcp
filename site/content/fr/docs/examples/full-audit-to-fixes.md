Le [prompt complet en français](/docs/examples/full-audit-to-fixes/#prompt-à-copier) est conservé dans le fichier canonique `examples/full-audit-to-fixes.md`. Copiez le texte à partir de « Prompt à copier » dans le projet à auditer.

Le prompt demande d’inventorier tous les outils et d’utiliser les capacités pertinentes. Il impose la création de l’epic et des issues GitHub avant les correctifs, puis l’implémentation et la validation des changements. Les accès, budgets et autorisations de publication doivent être vérifiés.

Il s’agit d’une instruction réutilisable, pas d’un audit exécuté. Aucun correctif ni gain SEO n’est déclaré par cet exemple.
